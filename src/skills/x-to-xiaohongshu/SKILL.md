# X长文转小红书图文生成器

输入一个推特长文链接，自动生成个人读后感文案，经过 Hook 和爆款检查优化后，生成适合小红书发布的配图。

## 核心任务

将推特上的长文内容转化为适合小红书平台传播的图文内容。通过提炼核心观点、融入个人见解、优化标题和文案结构，最终生成视觉吸引力强的配图，帮助用户快速完成从阅读到发布的全流程。

**目标**：
- 准确提取推特长文的核心观点和关键信息
- 生成有个人视角的读后感文案，避免简单搬运
- 通过 Hook 检查和爆款公式优化，提升内容传播潜力
- 生成 3-6 张符合小红书审美的配图，视觉统一且信息清晰

**关键约束**：
- 必须保留原作者观点的准确性，不曲解原意
- 读后感需体现个人思考，有独特价值
- 配图文字清晰可读，符合小红书平台规范
- 整个流程需要用户确认后再生成图片

## 执行步骤

### Step 1: 获取并解析推特内容

- 使用 fetch 工具获取推特链接的完整内容
- 识别并提取推特作者信息（用户名、发布时间）
- 提取长文的完整文本内容，保持段落结构
- 识别长文中的核心论点（通常 2-5 个主要观点）
- 提取关键数据、案例或金句（如果有）
- 记录推特原文链接，用于后续引用标注

### Step 2: 生成读后感文案

- 分析推特长文的核心价值：它解决了什么问题？提供了什么新视角？
- 融入个人思考：启发、经历、应用、共鸣点
- 构建读后感结构（建议 800-1200 字）：开篇引入 → 核心观点 → 个人见解 → 行动建议 → 结尾升华
- 语言风格：口语化但有深度，真诚不做作
- 在文末标注："灵感来源： @推特作者名 【原文链接】"

### Step 3: Hook 和爆款检查优化

**标题 Hook 检查**（生成 3-5 个标题选项）：
- 是否包含具体数字或对比？
- 是否制造好奇或反差？
- 是否直击痛点或欲望？
- 是否使用情绪词？
- 标题长度 15-25 字

**开篇 Hook 检查**：前 3 句话抓注意力，场景化或提问

**爆款要素检查**：
- [ ] 有明确的目标受众
- [ ] 有情绪共鸣点
- [ ] 有实用价值
- [ ] 有记忆点
- [ ] 有互动引导

生成 5-8 个小红书标签建议

### Step 4: 用户确认

**此步骤不可跳过！**

展示优化后的内容（标题、全文、标签）和配图方案，明确询问确认后方可进入 Step 5。

### Step 5: 生成小红书配图

- 配图数量 4-6 张：封面图 + 核心观点卡片 + 金句卡片 + 行动建议
- 视觉风格：简约杂志风（默认）、温暖手写风、专业商务风、活力青春风
- 每张图文字 50-100 字，3:4 竖版
- 使用 image_generate 工具逐张生成，保持视觉统一

### Step 6: 交付完整素材包

汇总：文案 + 标签 + 配图 + 原文来源标注 + 发布建议

**引用规范**：
- 文末标注："💡 灵感来源： @推特作者名"
- 原文链接标注
- 引用金句使用引号标注出处
